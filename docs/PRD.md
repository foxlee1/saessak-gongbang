# 사이트 설계도(PRD) — 새싹 공방

작성일: 2026-10-18 · 이 문서는 사이트를 고칠 때마다 다시 보는 기준이다.

## 1. 한 줄 정의
성수동에서 데이트·친구 모임 손님이 함께 향초·디퓨저를 만드는 원데이 클래스 공방.

## 2. 손님
- 누가: 데이트하는 커플, 친구끼리 오는 손님
- 어디서 알고 오나: 인스타그램 (프로필 링크 → 사이트)

## 3. 손님이 궁금한 것 (연락하기 전에)
1. 가격·인원 — 2인 기준 얼마인지, 몇 명까지 함께 할 수 있는지
2. 수업 시간·예약 가능일 — 몇 시간 걸리고 언제 갈 수 있는지
3. 만드는 것·가져가는 것 — 향초/디퓨저 중 무엇을 만들고, 완성품을 바로 가져가는지

## 4. 믿게 할 증거 (실제로 있는 것만)
- 수업·작품 사진 (사장님이 가진 실제 사진만 쓴다)
- 인스타그램 게시물 (인스타 링크·게시물 연결)
- 후기: 실제 손님 후기가 있음 — 사장님이 받은 원문 그대로만 넣는다. 받기 전까지는 자리만 둔다.

## 5. 누르게 할 버튼 하나
- 버튼 이름: 예약 신청하기
- 누르면: 예약 달력에서 날짜·시간 선택 → 예약 신청 폼

## 6. 페이지 구성 (위에서 아래로)
**메인 페이지 (/)**
1. 첫 화면 — 한 문장 + "예약 신청하기" 버튼
2. 이런 걸 만들어요 — 향초·디퓨저 소개, 완성품 가져가기 (사진)
3. 가격·시간 — 2인 5만원 / 2시간
4. 후기 자리 — 실제 후기 원문 (없으면 비워 둠) + 인스타 게시물 연결
5. 오시는 길 — 성수동 (상세 주소 미정)
6. 예약 신청 — 달력 + 폼

**그 밖의 페이지**
- 로그인·회원가입 (/login)
- 관리자 페이지 (/admin, 비밀번호로 잠금)

## 7. 문의 폼에서 받을 것
- 이름, 연락처
- 희망 날짜·시간 (예약 달력에서 고름)
- 만들고 싶은 것 (향초 / 디퓨저)
- 개인정보 수집·이용 동의 (필수)

## 8. 정확해야 하는 사실 (사용자가 말한 그대로)
- 가격: 2인 5만원
- 시간: 2시간
- 위치: 성수동 (상세 주소 미정)
- 연락 방법: 인스타 DM
- 최대 인원·수업 가능 요일·시간대: (미정 — 사장님이 /admin '수업 시간' 탭에서 시간과 받을 팀 수를 직접 연다)
- 완성품 당일 가져가기: (미정 — 확인 전까지 사이트에 적지 않음)
- 개인정보 보관 기간: 예약 폼에 "수업이 끝나고 1년 뒤 지워요"로 임시로 적어 둠 (사장님 확인 필요)

## 9. 이번에 넣지 않을 것
- 블로그·소식 글
- 온라인 결제 (입금은 공방이 따로 안내)

## 10. 첫 화면 한 문장 후보
1. 둘이서 2시간, 향기로 남는 하루 — 새싹 공방 향초·디퓨저 원데이 클래스
2. 오늘 만든 향, 오늘 들고 가요. 성수동 새싹 공방
3. 데이트도, 친구 모임도 향초 하나로 특별하게

## 11. 다음에 할 것
- 블로그·소식 글 메뉴
- 온라인 결제
- 상세 주소·지도, 최대 인원, 수업 가능 요일·시간대 채우기
- 실제 후기 원문 모아서 넣기

## 12. 만드는 방법 (클로드가 끝까지 만들 때 기준)
- 분위기: 발랄한 · 참고 디자인: 없음 — 클로드가 정함
- 문의 저장: 예 → Supabase(leaderpl-admin 스킬) + /admin
- 예약 달력 자동 확정: 필요 — 공방이 열어 둔 시간대만 고를 수 있고, 자리가 남아 있으면 바로 확정. 찬 자리는 막는다.
- 알림 메일·문자: 필요 — 새 예약이 들어오면 사장님에게 알림, 손님에게 확정 안내
- 회원가입: 필요 (Supabase Auth) → 개인정보 처리방침 페이지를 함께 만든다
- 배포: GitHub 공개 저장소 + Vercel

## 13. 만드는 순서 (클로드가 처음부터 끝까지 한 번에)
1. 스타일(색·글꼴)을 분위기에 맞게 정하고 첫 화면부터 만든다
2. GitHub 공개 저장소에 올리고 Vercel로 배포해 내 주소를 만든다
3. 예약 신청 폼 → Supabase 저장 → /admin 관리자 페이지까지 만든다
4. 예약 달력(열린 시간대·자동 확정)과 알림 메일·문자를 붙인다
5. 회원가입·로그인과 개인정보 처리방침을 붙인다
6. 다 만든 뒤 한 번에 보고: 내 사이트 주소 · 관리자 주소 · 확인 방법 · 사용자가 할 일
- 사용자가 직접 할 일(이때만 멈춤): 로그인, 결제, 관리자 비밀번호(ADMIN_PASSWORD) 입력, 알림 메일·문자 서비스 가입
